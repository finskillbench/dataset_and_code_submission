# Portfolio Construction — Data Dictionary

Dataset for the Portfolio Construction skill (V2a Skill 2). Contains daily prices, factor exposures, covariance matrices, expected-return views, constraint sets, optimizer-derived ground truth portfolios, and benchmark task episodes for 30 S&P 500 tickers across 2024–2025.

Generated by `python -m scripts.portfolio_construction.run_pipeline`.

---

## File Schemas

### `raw/fmp_prices/{TICKER}.json`

provider daily OHLCV price history. Array of daily records.

| Field | Type | Description |
|---|---|---|
| `date` | string | Trading date (YYYY-MM-DD) |
| `open` | float | Opening price |
| `high` | float | Daily high |
| `low` | float | Daily low |
| `close` | float | Closing price (split-adjusted) |
| `adjClose` | float | Adjusted close |
| `volume` | int | Daily volume |

### `raw/fmp_market_cap/{TICKER}.json`

provider historical market capitalization. Array of daily records with `date` and `marketCap` fields.

### `raw/ff/ff5_daily.parquet` / `momentum_daily.parquet`

Fama-French 5-factor + momentum daily returns from Ken French Data Library.

| Column | Type | Description |
|---|---|---|
| `date` | date | Trading date |
| `Mkt-RF` | float | Market excess return |
| `SMB` | float | Small minus big |
| `HML` | float | High minus low (value) |
| `RMW` | float | Robust minus weak (profitability) |
| `CMA` | float | Conservative minus aggressive (investment) |
| `RF` | float | Risk-free rate |
| `Mom` | float | Momentum factor (in momentum file) |

### `processed/prices.parquet`

Wide-format daily price panel. Columns are ticker symbols, index is trading date.

### `processed/returns.parquet`

Wide-format daily simple returns. Columns are ticker symbols, index is trading date.

### `processed/factor_exposures.parquet`

Rolling OLS factor betas (252-day window) for each ticker against FF5 + momentum.

| Column | Type | Description |
|---|---|---|
| `date` | date | Estimation date |
| `symbol` | string | Ticker symbol |
| `mkt_rf` | float | Market beta |
| `smb` | float | Size beta |
| `hml` | float | Value beta |
| `rmw` | float | Profitability beta |
| `cma` | float | Investment beta |
| `mom` | float | Momentum beta |

### `processed/benchmark_weights.parquet`

Market-cap-weighted benchmark portfolio weights, rebalanced monthly.

| Column | Type | Description |
|---|---|---|
| `date` | date | Month-end date |
| `{TICKER}` | float | Benchmark weight for each ticker (sums to 1.0) |

### `processed/covariance/{YYYY-MM-DD}.npz`

Ledoit-Wolf shrinkage covariance matrix estimated from trailing 252-day returns. NumPy compressed archive containing:
- `cov`: NxN covariance matrix (annualized)
- `symbols`: array of ticker symbols (column/row order)
- `date`: estimation date string

### `processed/covariance/_manifest.json`

Lists all available covariance dates, symbol order, and estimation parameters (window size, shrinkage method).

### `processed/constraints/{difficulty}.json`

Constraint set specification. Three tiers: `easy`, `medium`, `hard`.

| Field | Type | Description |
|---|---|---|
| `long_only` | bool | Whether short positions are prohibited |
| `max_weight` | float | Maximum weight per single name |
| `min_weight` | float | Minimum weight per name (if held) |
| `sector_limits` | object | Max weight per GICS sector (sector name → float) |
| `min_names` | int | Minimum number of holdings |
| `max_names` | int | Maximum number of holdings |
| `max_turnover` | float/null | Maximum one-way turnover (null = unconstrained) |
| `max_tracking_error` | float/null | Maximum tracking error vs benchmark (null = unconstrained) |
| `factor_neutrality` | bool | Whether factor-neutral constraint is active |
| `description` | string | Human-readable summary |

### `processed/views/{YYYY-MM-DD}.json`

Composite expected-return view for a given month-end date. Built from 5 signals using Grinold-Kahn alpha scaling.

| Field | Type | Description |
|---|---|---|
| `date` | string | Month-end date (YYYY-MM-DD) |
| `n_symbols` | int | Number of symbols in the universe |
| `signals` | object | Dict of signal name → {ticker → raw signal value} |
| `composite_z` | object | Ticker → composite z-score (weighted combination of signals) |
| `expected_returns` | object | Ticker → daily expected return (scaled from composite z) |

Signal names: `earnings_yield`, `roe`, `momentum_12_1`, `eps_revision`, `low_vol`.

### `ground_truth/{date}_{difficulty}_{objective}.json`

Optimizer-derived reference portfolio for a given date, constraint tier, and objective.

| Field | Type | Description |
|---|---|---|
| `status` | string | `optimal` or `infeasible` |
| `weights` | object | Ticker → portfolio weight (sums to 1.0) |
| `expected_return` | float | Annualized expected portfolio return |
| `expected_risk` | float | Annualized portfolio volatility |
| `sharpe_ratio` | float | Expected Sharpe ratio |
| `active_weights` | object | Ticker → active weight vs benchmark |
| `tracking_error` | float | Annualized tracking error vs benchmark |
| `turnover` | float | One-way turnover from benchmark |
| `constraint_satisfaction` | object | Constraint name → bool (pass/fail) |
| `diagnostics` | object | Solver metadata (`solver_status`, `objective_value`) |

Objectives: `max_sharpe`, `min_variance`, `max_return`, `risk_parity`.
Difficulties: `easy`, `medium`, `hard`.
Filename convention: `{YYYY-MM-DD}_{difficulty}_{objective}.json`

### `ground_truth/black_litterman/{YYYY-MM-DD}.json`

Black-Litterman posterior portfolio for a given date.

| Field | Type | Description |
|---|---|---|
| `status` | string | `optimal` or `infeasible` |
| `posterior_returns` | object | Ticker → BL posterior expected return |
| `posterior_weights` | object | Ticker → optimal weight under posterior |
| `view_adjustments` | object | View specification and prior/posterior return comparison |
| `view_adjustments.view.type` | string | `absolute` or `relative` |
| `view_adjustments.view.symbols` | array | Tickers involved in the view |
| `view_adjustments.view.return` | float | View return magnitude |
| `view_adjustments.view.confidence` | float | View confidence (0–1) |

### `episodes/_manifest.json`

Task counts by type.

| Field | Type | Description |
|---|---|---|
| `{task_type}.count` | int | Number of tasks of this type |
| `{task_type}.description` | string | Task type label |

Task types: `unconstrained` (12), `constrained` (12), `rebalancing` (6), `tool_use_parameterization` (10), `infeasibility_detection` (10), `black_litterman` (2). Total: 52 tasks.

### `validation/summary.json`

9-check data quality validation report.

| Field | Type | Description |
|---|---|---|
| `run_date` | string | ISO timestamp |
| `universe_size` | int | Number of tickers |
| `checks` | object | Check name → result |
| `overall_status` | string | Worst status across all checks |

Checks: `price_coverage`, `return_anomalies`, `factor_coverage`, `factor_exposure_reasonableness`, `covariance_psd`, `view_coverage`, `constraint_feasibility`, `ground_truth_quality`, `leakage_audit`.
