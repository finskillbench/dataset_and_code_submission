# Fundamental Analysis — Data Dictionary

Dataset for the Fundamental Analysis skill (V2a Skill 1). Contains SEC regulatory filings filings, XBRL financial facts, provider pre-parsed statements, revenue segment data, and ground truth labels for 3 sub-tasks (normalization, earnings quality, driver decomposition) across 30 S&P 500 tickers.

Generated by `python -m scripts.fundamental_analysis.run_pipeline`.

## File Schemas

### `raw/edgar/submissions/{cik}.json`

regulatory filings Company Submissions metadata downloaded via `edgartools`. Contains filing history, company info, and CIK-to-ticker mapping.

### `raw/edgar/xbrl/{cik}.json`

regulatory filings CompanyFacts (XBRL) bulk JSON. Contains all reported XBRL facts for a company across all filings, organized by taxonomy and tag.

### `raw/provider/{endpoint}/{ticker}.json`

financial data API response for a given financial statement endpoint and ticker. Array of period records with fields like `date`, `period`, `revenue`, `netIncome`, etc. Naming follows provider's camelCase convention.

### `processed/filings/{cik}/{accession}/metadata.json`

| Field | Type | Description |
|---|---|---|
| `accession_number` | string | SEC accession number (e.g. `0000320193-24-000069`) |
| `form_type` | string | Filing type: `10-K`, `10-Q`, `20-F`, `40-F`, `6-K` |
| `filing_date` | string | Date filed with SEC (YYYY-MM-DD) |
| `period_of_report` | string | Fiscal period end date (YYYY-MM-DD) |
| `cik` | string | 10-digit zero-padded CIK |
| `symbol` | string | Ticker symbol |

### `processed/filing_timeline.parquet`

Unified timeline merging regulatory filings filing metadata with provider period data.

| Column | Type | Description |
|---|---|---|
| `symbol` | string | Ticker symbol |
| `cik` | string | 10-digit zero-padded CIK |
| `form_type` | string | Filing type (`10-K`, `10-Q`, `20-F`, etc.) |
| `period_end` | date | Fiscal period end date |
| `filing_date` | date | Date filed with SEC |
| `accession_number` | string | SEC accession number |
| `filer_type` | string | `domestic` or `foreign` |
| `xbrl_taxonomy` | string | `us-gaap` or `ifrs-full` |
| `sector` | string | GICS sector |
| `country` | string | Country of incorporation |

### `processed/xbrl_panel.parquet`

Flattened panel of canonical financial metrics extracted from XBRL CompanyFacts.

| Column | Type | Description |
|---|---|---|
| `symbol` | string | Ticker symbol |
| `period_end` | date | Fiscal period end date |
| `canonical` | string | Normalized metric name (e.g. `revenue`, `net_income`, `total_assets`) |
| `value` | float | Metric value in USD (not scaled) |
| `duration_class` | string | `quarterly` or `annual` |
| `source_tag` | string | Original XBRL tag name |
| `taxonomy` | string | `us-gaap` or `ifrs-full` |

Canonical metric names: `revenue`, `operating_income`, `net_income`, `eps_diluted`, `total_assets`, `total_liabilities`, `stockholders_equity`, `operating_cash_flow`, `ebitda`.

### `ground_truth/normalization/{TICKER}_{YYYY-MM-DD}.json`

Per-ticker, per-period normalization ground truth label.

| Field | Type | Description |
|---|---|---|
| `symbol` | string | Ticker symbol |
| `period_end` | string | Fiscal period end date (YYYY-MM-DD) |
| `form_type` | string | Filing type that covers this period |
| `filing_date` | string | Date the filing was submitted to SEC |
| `metrics` | object | Dict of canonical metric names → metric objects |
| `metrics.{name}.value` | float | Normalized metric value (USD, unscaled) |
| `metrics.{name}.source` | string | Provenance: `regulatory+provider` (both agree), `xbrl`, `provider`, or `computed` |
| `metrics.{name}.confidence` | string | `high` (sources agree), `medium` (computed/derived), `low` (single source, flow metric) |
| `xbrl_fmp_agreement` | bool | Whether XBRL and provider values agree within tolerance for key metrics |
| `tier` | int | Annotation tier: `2` = semi-automated (regulatory+provider cross-reference) |

Filename convention: `{TICKER}_{period_end}.json`

### `ground_truth/normalization_panel.parquet`

All normalization labels concatenated into a single Parquet panel for bulk analysis.

### `ground_truth/earnings_quality/{TICKER}_{YYYY-MM-DD}.json`

Per-ticker, per-period earnings quality ground truth. Computed from provider quarterly financial statements.

| Field | Type | Description |
|---|---|---|
| `symbol` | string | Ticker symbol |
| `period_end` | string | Fiscal period end date (YYYY-MM-DD) |
| `period` | string | provider period label (Q1–Q4, FY) |
| `form_type` | string | Filing type |
| `filing_date` | string | Date filed with SEC |
| `piotroski` | object | Piotroski F-Score (0–9) with 9 binary components |
| `piotroski.score` | int | Composite score |
| `piotroski.components` | object | 9 binary signals (roa_positive, cfo_positive, delta_roa_positive, accruals_negative, delta_leverage_negative, delta_current_ratio_positive, no_dilution, delta_gross_margin_positive, delta_asset_turnover_positive) |
| `beneish` | object | Beneish M-Score with 8 variable components |
| `beneish.m_score` | float | Composite M-Score (> −1.78 = manipulation likely) |
| `beneish.flag_manipulation_likely` | bool | Whether M-Score exceeds threshold |
| `beneish.components` | object | 8 ratios: dsri, gmi, aqi, sgi, depi, sgai, lvgi, tata |
| `accruals_ratio` | float | (Net Income − OCF) / Total Assets |
| `income_quality_ratio` | float | OCF / Net Income (from provider key-metrics) |
| `flags` | array | List of triggered flags: `low_piotroski`, `beneish_manipulation_flag`, `high_accruals`, `negative_income_quality` |
| `flag_count` | int | Number of flags triggered |
| `tier` | int | `2` = computed from provider statements |

### `ground_truth/driver_decomposition/{TICKER}_{prev_date}_to_{curr_date}.json`

Per-ticker, per-consecutive-quarter-pair driver decomposition ground truth. Computed from provider segment data and income statements.

| Field | Type | Description |
|---|---|---|
| `symbol` | string | Ticker symbol |
| `current_period_end` | string | Current quarter end date |
| `prior_period_end` | string | Prior quarter end date |
| `filing_date` | string | Filing date for the current period |
| `revenue_delta` | int | Revenue change in USD (current − prior) |
| `top_revenue_drivers` | array | Top 7 revenue drivers ranked by absolute contribution |
| `top_revenue_drivers[].driver` | string | Segment or region name |
| `top_revenue_drivers[].type` | string | `product_segment` or `geographic_segment` |
| `top_revenue_drivers[].direction` | string | `increase`, `decrease`, or `flat` |
| `top_revenue_drivers[].magnitude_usd` | int | Dollar change |
| `top_revenue_drivers[].contribution_pct` | float | % of total revenue change |
| `product_segment_drivers` | array | Full product segment breakdown |
| `geographic_segment_drivers` | array | Full geographic segment breakdown |
| `margin_drivers` | array | Margin change drivers (gross margin, opex ratios) |
| `margin_drivers[].driver` | string | Metric name (gross_margin, operating_margin, sga_ratio, etc.) |
| `margin_drivers[].delta_pp` | float | Change in percentage points |
| `has_product_segments` | bool | Whether product segment data was available |
| `has_geographic_segments` | bool | Whether geographic segment data was available |
| `tier` | int | `2` = computed from provider segment + statement data |

### `raw/provider/revenue-product-segmentation/{TICKER}.json`

provider quarterly revenue breakdown by product/business segment. Array of period records.

| Field | Type | Description |
|---|---|---|
| `symbol` | string | Ticker symbol |
| `date` | string | Period end date |
| `period` | string | Q1–Q4 or FY |
| `data` | object | Segment name → revenue in USD |

### `raw/provider/revenue-geographic-segmentation/{TICKER}.json`

provider quarterly revenue breakdown by geographic region. Same schema as product segmentation.

### `validation/summary.json`

12-check data quality validation report.

| Field | Type | Description |
|---|---|---|
| `run_date` | string | ISO timestamp of validation run |
| `universe_size` | int | Number of tickers in the pipeline run |
| `checks` | object | Dict of check name → result object |
| `checks.{name}.status` | string | `PASS`, `WARN`, `FAIL`, or `SKIP` |
| `overall_status` | string | Worst status across all checks |

Checks: `security_master_completeness`, `edgar_coverage`, `fmp_coverage`, `xbrl_coverage`, `filing_sequence`, `filing_date_sanity`, `section_extraction`, `xbrl_fmp_agreement`, `filing_metadata_agreement`, `temporal_ordering`, `future_data_leakage`, `ground_truth_independence`.
